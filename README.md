# sumitsengar.me

The source code for my personal blog and writing space, live at [sumitsengar.me](https://sumitsengar.me).

## About

This site is a quiet space on the web for publishing thoughts, essays, and personal reflections on life, books, cinema, and everyday moments.

The design is kept intentional and distraction-free, focusing on clean typography and comfortable reading.

## Tech and Highlights

Pure HTML, CSS, and vanilla JavaScript with zero frameworks or build dependencies

Dark and light theme switcher with saved preference in local storage

Automated reading time calculation for essays

Editorial typography pairing Playfair Display with Lato

Hosted on GitHub Pages with a custom domain

## Structure

```
assets/
  css/       Stylesheets for the homepage and reading view
  fonts/     Local font files
  js/        Theme toggler and site scripts
  favicon/   Site icons and web manifest
posts/       Article template and future essays
index.html   Homepage and post index
CNAME        Custom domain configuration
```

## Status

The layout, theme engine, and article templates are complete. The blog currently has no published posts yet. Writings will be added here as new essays are written.
